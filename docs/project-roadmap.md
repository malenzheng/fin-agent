# 项目路线

更新日期：2026-10-04。定位保持“金融市场信息处理 + 投研辅助 + Agent 评测”，以中文求职作品集为交付目标。

## 已落地：可复现的离线基线

- [x] 保留行情特征、周线评分、缓存边界与原有 smoke。
- [x] 合成资讯 schema 与只读 provider 接口。
- [x] 标的、发布时间、可获得时间、新鲜度筛选；冲突 ID 拒绝。
- [x] 催化、风险与背景原文摘录；证据清单；JSON / Markdown；执行轨迹。
- [x] 信息不足状态和无风险资料说明。
- [x] 6 个合成回归任务与 7 个规则评分项。
- [x] 对未知引用、伪造摘录、改写证据、未来信息与风险遗漏的测试。
- [x] 支持评测已有简报 JSON，保存分项失败原因。
- [x] 中文文档和自动测试工作流配置。
- [x] 参照美股选股项目实现长桥 OAuth/API Key、只读验证、美股日 K 与独立缓存入口。

本阶段的摘录、标注与任务是人工构造的工程样例，不能称为真实投研 Agent 能力测评。

## 下一阶段：公开资料进入研究流程

- [ ] 选择一种公开公告来源，存储原始文件、抓取时间、发布方与来源链接。
- [ ] 将已接入的长桥真实日 K 数据入口连到候选池；行情与资讯保持各自的来源标识。
- [ ] 建立公司与证券标识映射、分页、限流、幂等入库、内容指纹与重试。
- [ ] 抽取文档段落并保留页码或位置，建立证据 ID。
- [ ] 人工标注首批真实案例，并按公司、文档或时间隔离开发集与测试集。

验收：对同一研究时点重放，得到可解释、可追溯的资料集合；来源失败有明确诊断。真实资料失败不能静默混入合成资料。

## 再下一阶段：LLM 研究工作流

- [ ] 给模型提供查询资料、读取证据、数值计算三个只读工具。
- [ ] 增加调用预算、超时、停止条件、结构化输出校验和失败记录。
- [ ] 把原文证据、模型分析与待核实假设分别表达。
- [ ] 与同一任务下的规则基线、单轮 Prompt 基线比较。

验收：每个结论能回到证据；缺少资料时能明确停止；记录 token、耗时、工具调用次数和错误类别。

## 评测扩展与 Agentic RL

- [ ] 扩展到 30-50 个独立标注任务，包含财报比较、指标计算、相互矛盾资料和信息不足。
- [ ] 为数值、年份、单位和引用建立确定性检查；为推理和改写建立人工 Rubric。
- [ ] 检查 LLM-as-Judge 与人工评分的一致性，再考虑作为辅助评分。
- [ ] 从失败轨迹构造 SFT 样本；需要偏好优化时准备成对比较数据。
- [ ] 在独立评测稳定后开展小规模 Agentic RL 实验，比较收益、成本和奖励漏洞。

验收：报告包含测试集定义、基线、失败案例和成本；不把规则样例满分或训练奖励提升当作泛化证据。
